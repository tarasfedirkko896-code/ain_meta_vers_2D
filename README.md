# AIN 2D — Stage Prototype 01
Окремий новий проєкт. Поточна карта ain_conference_22 не змінена.

## Перегляд
Відкрийте index.html у браузері. Працює без сервера й інтернету.
Рух: WASD або стрілки. Кнопка показує заблоковані клітинки.
preview.png — загальний вигляд.

## Карта
map.tmj — карта Tiled / WorkAdventure (32×32 px тайли).
assets/tiles.png — невеликий атлас окремих повторно використовуваних елементів.
Підлога, меблі, стіни та стартова зона зберігаються окремими шарами.
assets/display.png та assets/sign.png — вихідні панелі; після зміни генератора запустіть build.py для перебудови атласу.
build.py — вихідний генератор (Python 3 + Pillow).
validation.json — результат перевірки зв'язності проходів.

Це прототип ділянки сцени, не вся конференція і не фінальний дизайн.
100 крісел для перевірки масштабу. Фінальна зала на 200 потребує розширення.
Напис ain на екрані — тимчасовий текст, не фінальний фірмовий логотип.
Звукові зони Podium/Audience та доступ спікерів ще не налаштовані.
Перевірено структуру даних і проходи, імпорт у WorkAdventure ще не перевірено.
Крісла прохідні; стіни, рослини й столи блокують рух.

## Безпечне окреме розгортання
Створіть НОВИЙ репозиторій ain-2d-stage-prototype і нову тестову кімнату.
Завантажте цю папку у новий репозиторій; після GitHub Pages використовуйте URL map.tmj.
Не замінюйте файли ain_conference_22 і URL поточної кімнати.
Папка backup у загальному архіві містить незмінений попередній пакет v23.
