ЗАВАНТАЖЕННЯ НА GITHUB
1. Розпакуйте цей ZIP.
2. У репозиторії ain_meta_vers_2D натисніть Add file → Upload files.
3. Перетягніть ВСІ розпаковані файли разом у корінь репозиторію.
4. Commit changes. Дочекайтеся зеленої позначки GitHub Pages.
5. URL нової версії:
https://tarasfedirkko896-code.github.io/ain_meta_vers_2D/map-2d-v2.tmj

Новий URL допоможе відрізнити цю версію від попереднього простого прототипу.
Файли не потребують папки assets. Стара карта ain_conference_22 не змінена.

ПЕРЕВІРКА ДО ПУБЛІКАЦІЇ
Відкрийте walk-test.html у браузері. Він працює без інтернету.
WASD/стрілки — рух; клік на підлозі — маршрут; колесо — масштаб.
«До сцени» — перейти до входу в залу.
«Перевірити перекриття» — перейти до місця під верхнім шаром.
«Сховати верхній шар» — побачити різницю у відображенні персонажа.
«Межі руху» — показати всі заблоковані клітинки червоним.

ЩО ЗМІНЕНО
43 шари Tiled: підлога/архітектура, сцена, два блоки крісел,
8 стендів, центральний AIN, таблички, навіси та верхівки рослин.
Верхні шари розміщені над floorLayer — персонаж проходить позаду них.
Графіка попередньої карти збережена без перерисовування логотипів.
Межі руху й стартові клітинки перенесені з v23 без змін.
Це гібридна 2D-карта: частина архітектури залишається намальованою.
Не кожен предмет є окремою сутністю в редакторі WorkAdventure;
окремі тайлові шари можна редагувати у Tiled.
При переміщенні намальованих об'єктів може знадобитися доробка підлоги під ними.

ПЕРЕВІРЕНО
JSON, текстури (до 2048 px), відповідність графіки v23,
зв'язність усіх 9222 прохідних клітинок, 64 стартові клітинки.
Логіка тестової прогулянки перевірена автоматично без браузерного рендерингу.
Реальний імпорт і гра у WorkAdventure ще не перевірені.
Зони звуку Podium/Audience та права спікерів налаштовуються окремо.
